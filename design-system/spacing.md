# Spacing System

## 1. Purpose

Spacing establishes hierarchy, rhythm and visual quality.

Do not treat spacing as arbitrary decoration.

---

## 2. Consistency

Use a coherent spacing scale.

Prefer design tokens or a consistent spacing system instead of random
values throughout the code.

---

## 3. Hierarchy Through Space

Use spacing to communicate relationships.

Smaller spacing generally indicates stronger relationships.

Larger spacing generally indicates separation between concepts.

---

## 4. Section Spacing

Sections should have deliberate vertical rhythm.

Avoid making every section exactly the same height.

Spacing should respond to:

- content density
- importance
- imagery
- hierarchy
- viewport

---

## 5. Component Spacing

Maintain consistent relationships between:

- heading and paragraph
- label and input
- icon and text
- title and supporting content
- content and CTA

---

## 6. Container Width

Use appropriate maximum widths.

Do not make text span the entire screen simply because space exists.

Do not use unnecessarily narrow containers.

Choose widths based on:

- content
- readability
- composition
- screen size

---

## 7. Responsive Spacing

Spacing should adapt across breakpoints.

Mobile should not simply receive desktop spacing scaled down.

Some sections may require:

- reduced padding
- different alignment
- different content order
- different composition

---

## 8. Whitespace

Whitespace should create:

- focus
- breathing room
- rhythm
- hierarchy

Do not use excessive whitespace to artificially create a "luxury"
appearance.

---

## 9. Avoid Random Values

If several elements should have the same spacing relationship,
reuse the same token.

Avoid arbitrary one-off values unless the composition genuinely
requires them.

---

## 10. Final Spacing Review

Ask:

- Does the page breathe?
- Is content grouped logically?
- Are sections too compressed?
- Are sections too empty?
- Is spacing consistent?
- Does mobile remain comfortable?
- Does spacing reinforce hierarchy?

# Typography System

## 1. Typography Is Identity

Typography should contribute significantly to the client's visual
personality.

Do not treat typography as an afterthought.

---

## 2. Do Not Default to Inter

Inter is allowed when appropriate.

It must not be the automatic choice for every project.

Consider alternatives based on:

- brand
- industry
- audience
- tone
- readability
- language
- performance

---

## 3. Font Pairing

Use a small number of complementary typefaces.

Common approaches include:

- one family for everything
- display + body
- serif display + sans body
- sans display + serif body

Do not use multiple fonts merely to make a design appear sophisticated.

---

## 4. Hierarchy

Define clear roles for:

- display
- H1
- H2
- H3
- H4
- body
- small text
- labels
- navigation
- buttons
- metadata

Hierarchy should be visible through a combination of:

- size
- weight
- spacing
- line height
- color
- width

---

## 5. Display Typography

Large typography can create impact.

Do not automatically use enormous headings.

Display text should remain:

- readable
- intentional
- appropriate to the brand
- responsive

---

## 6. Body Typography

Prioritize readability.

Consider:

- font size
- line height
- line length
- contrast
- paragraph spacing

Avoid excessively narrow or excessively wide text columns.

---

## 7. Line Length

Long lines reduce readability.

For reading-heavy content, use a comfortable text measure.

Do not make every section full-width simply because the viewport is
wide.

---

## 8. Responsive Typography

Typography should adapt across:

- mobile
- tablet
- desktop
- large desktop

Prevent:

- awkward wrapping
- clipped text
- excessive heading size
- unreadably small text

---

## 9. Font Weight

Use weight intentionally.

Do not make everything bold.

Establish hierarchy through multiple typographic variables.

---

## 10. Letter Spacing

Use letter spacing carefully.

It can help with:

- uppercase labels
- display typography
- navigation
- editorial treatments

Do not overuse tracking.

---

## 11. Typography and Culture

Consider language and cultural context.

A font that works beautifully for English may not work equally well
for another writing system.

Prioritize readability and appropriate glyph support.

---

## 12. Performance

Avoid loading unnecessary font families and weights.

Only load what the project actually uses.

---

## 13. Final Typography Review

Ask:

- Does the typography fit the client?
- Is hierarchy obvious?
- Is body text comfortable?
- Are headings appropriately sized?
- Is the typeface distinctive without being distracting?
- Is the typography responsive?
- Is the number of fonts justified?

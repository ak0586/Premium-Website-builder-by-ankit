# Layout and Composition System

## 1. Layout Is Communication

Layout should help users understand:

- what matters
- what belongs together
- what comes next
- what action to take

---

## 2. Start With Content

Choose layout based on content.

Do not force every client into the same template.

---

## 3. Composition Variety

Appropriate layouts may include:

- split hero
- editorial layout
- asymmetric composition
- structured grid
- image-led section
- timeline
- process
- comparison
- feature spotlight
- testimonial composition
- service list
- full-width visual section
- narrow reading section

Use variation intentionally.

---

## 4. Avoid Repetitive Section Patterns

Avoid automatically repeating:

heading
subtitle
three cards
CTA

throughout the page.

Repetition should occur only when the content benefits from it.

---

## 5. Grid

Use grids when they improve organization.

Do not use cards simply because a grid is easy to generate.

Consider:

- alignment
- column count
- hierarchy
- whitespace
- content density

---

## 6. Asymmetry

Asymmetry can create personality and visual interest.

Use it intentionally.

Do not create asymmetry merely to appear creative.

---

## 7. Hero Sections

The hero should communicate quickly:

- what the business is
- what value it provides
- who it serves
- what the user can do next

Possible hero approaches include:

- typography-led
- image-led
- split composition
- editorial
- product/service focused
- location focused
- minimal

Do not default to the same hero structure.

---

## 8. Navigation

Navigation should reflect information architecture.

Keep it:

- clear
- predictable
- accessible
- responsive

Do not add unnecessary navigation items.

---

## 9. Section Transitions

Use visual transitions when they improve rhythm.

Possible tools:

- background changes
- spacing
- imagery
- borders
- typography
- subtle motion

Avoid decorative transitions between every section.

---

## 10. Responsive Composition

Desktop and mobile may require different composition.

Allow:

- reordered content
- different alignment
- different image placement
- different grid structures
- simplified decorative elements

Do not force desktop composition onto mobile.

---

## 11. Content Density

Premium does not mean empty.

Premium does not mean crowded.

Find the appropriate density for:

- industry
- audience
- content
- conversion goal

---

## 12. Final Layout Review

Ask:

- Is the hierarchy clear?
- Does the page have rhythm?
- Is composition varied?
- Are important elements emphasized?
- Is the layout appropriate to the client?
- Does mobile remain intentional?
- Is anything present merely to fill space?

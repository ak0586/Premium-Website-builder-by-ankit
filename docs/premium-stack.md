# Premium UI Stack

Every client website should be capable of achieving premium,
production-quality UI.

The standard toolkit includes:

- CSS / native browser capabilities (transitions, transforms, animations)
- shadcn/ui
- Motion
- React Bits
- Magic UI
- Lottie / Rive (preferred for lightweight vector animation and the AI concierge avatar)
- Lucide icons where appropriate
- Three.js / WebGL / PBR shaders (strictly for the optional, justified 3D flagship moment only)

These are tools, not visual identities.

Every project should use the smallest appropriate subset.

Premium quality comes from:

- creative direction
- typography
- color
- composition
- imagery
- spacing
- hierarchy
- interaction
- motion
- responsive behavior
- accessibility
- performance
- content
- refinement

A website does NOT become premium merely by using animation libraries.

Libraries should accelerate implementation of good design decisions.

They must never replace design decisions.
